XR Workspace · running panel redesign

The Omarchy panel plugin (omarchy-plugin/cody.viture-workspace/) while a session runs: RunningPage.qml. Same 520 × 660 window, header, device card, big button and shell kit as the pre-start pages. Every session option is in the glasses (gear menu, glass pills, keys). The panel keeps what still works when the glasses' picture or tracking does not: Stop, Recenter, the state and what is wrong.

Starting, stopping, failed and recovery-needed states are not drawn here: the pre-start ProgressPage, RecoveryPage and Home own them. In privacy mode (Ctrl+Alt+D) the monitor is off, so this panel cannot be seen either: only Ctrl+Alt+D again, or stopping the session, brings it back.
